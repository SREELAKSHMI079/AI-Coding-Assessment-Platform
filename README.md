# AI Coding Assessment Platform

A platform built using C# .NET and ASP.NET Core Web API following **Clean Architecture** principles.

---

## Technical Constraints & Stack

- **Language**: C# (.NET 8 / 10 preview)
- **IDE**: Visual Studio / Visual Studio Code
- **Backend Framework**: ASP.NET Core Web API
- **ORM**: Entity Framework Core
- **Database**: Microsoft SQL Server
- **API Documentation**: OpenAPI / Swagger
- **Authentication**: ASP.NET Core Authentication & Authorization (Role-based: `User`, `Admin`)
- **AI Integration**: External AI Provider abstraction (`IAIFeedbackService`)
- **Code Execution**: Dedicated isolated code execution abstraction (`ICodeExecutionService`)

## Architectural Dependency Direction

```
API Layer (Presentation)
    ↓
Application Layer (Use Cases)
    ↓
Domain Layer (Enterprise Core)
```
- `Infrastructure` implements interfaces from `Application` and `Domain`.
- `Domain` has **zero** internal project dependencies.

---

## Core Domain Entities

1. **User**: Represents registered platform users (User or Admin roles).
2. **Problem**: Represents coding assessment challenges with constraints, difficulty, tags, and sample test cases.
3. **TestCase**: Represents input/output test cases linked to a specific problem.
4. **Submission**: Tracks user-submitted code, execution runtime metrics, and status.
5. **AIFeedback**: Stores structured feedback generated by external AI services (Correctness, Efficiency, Readability, Suggestions).

## How to Build

To compile all projects in the solution:

```bash
dotnet build AI.CodingAssessment.sln
```

To run unit and integration tests:

```bash
dotnet test AI.CodingAssessment.sln
```
